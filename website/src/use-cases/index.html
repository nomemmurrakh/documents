Use Cases

These are five common situations where an app needs one typed, reactive document. Each page walks through a realistic example and links back to the Guide pages that cover the details.

  • Settings & Preferences: the job that SharedPreferences and NSUserDefaults usually do, with typed values you can observe.
  • Session & User State: the signed-in user, auth tokens, and the active profile.
  • Caches & Drafts: the last synced payload, in-progress form drafts, and "continue where you left off."
  • Reactive UI State: any state that Compose or SwiftUI should re-render on.
  • Shared KMP Persistence: one storage API in shared code that runs on both Android and iOS.
