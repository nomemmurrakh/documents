Settings & Preferences

Settings are the job that SharedPreferences and NSUserDefaults usually do: theme, locale, feature flags, and onboarding state. Here they are typed and observable, instead of a flat bag of string keys.

@Serializable
enum class Theme { SYSTEM, LIGHT, DARK }

@Serializable
data class AppSettings(
    val theme: Theme = Theme.SYSTEM,
    val locale: String = "en-US",
    val hasCompletedOnboarding: Boolean = false,
)

class SettingsRepository {
    private val doc = Documents.document<AppSettings>("app-settings")

    var theme: Theme by doc.field(AppSettings::theme, default = Theme.SYSTEM)
    var locale: String by doc.field(AppSettings::locale, default = "en-US")

    val themeFlow: Flow<Theme> = doc.fieldFlow(AppSettings::theme, default = Theme.SYSTEM)
}

Each setting reads and writes like an ordinary property. Changing theme touches only that field's key. themeFlow lets your UI update as soon as the theme changes, with no polling and no need to read the rest of the settings object. See Field Delegates for how field() and fieldFlow() work.
