Quick Start

This walkthrough covers the whole flow in one place. There is no schema, no DAO, and no serialization code to write by hand. The example is a single offline note, the kind of "continue where you left off" document this library is built for.

1. Declare a data class

Start with an @Serializable data class:

import com.nomemmurrakh.documents.Documents
import com.nomemmurrakh.documents.document
import kotlinx.serialization.Serializable

@Serializable
data class Note(
    val title: String = "",
    val body: String = "",
    val done: Boolean = false,
)

2. Open a document

Opening a document takes one call and no configuration:

val note = Documents.document<Note>("note-1")

3. Write the whole object

Use set when you have a complete value, for example when you create the note for the first time:

note.set(Note(title = "Pick up milk", body = "2%, not whole"))

4. Change one field

Use update(prop, value) to change a single field. It writes only that one key and does not read the rest of the note:

note.update(Note::done, true)

5. Change several fields

Use update { current -> ... } to edit more than one field at once. The builder receives the current value and returns a new one with copy(). Fields you do not touch, such as done here, keep their values:

note.update { current ->
    current.copy(
        title = "Pick up oat milk",
        body = "The barista-approved kind",
    )
}

println(note.get()) // Note(title=Pick up oat milk, body=The barista-approved kind, done=true)
note.delete()
println(note.exists()) // false

Which write to use

get() returns null if the document has never been written. The three ways to write have different purposes:

  • set(value) replaces the whole document.
  • update(prop, value) writes a single field and does not read anything first.
  • update { current -> ... } reads the current value, or the type's defaults if nothing is stored, and writes back a new one. The read and the write happen atomically, so use it for edits that touch more than one field together.
