Installation

com.nomemmurrakh:documents is published on Maven Central. Add it to the commonMain source set of a Kotlin Multiplatform module, or to a plain Android module:

// build.gradle.kts
dependencies {
    implementation("com.nomemmurrakh:documents:0.2.0")
}
iOS: linking MMKV

On iOS, your app also needs to add MMKV to its own target, through CocoaPods or Swift Package Manager, the same way as any other native dependency. If it is missing, the build fails with a link error. See Troubleshooting for details.

No setup needed

The library initializes MMKV for you the first time it is used. On Android this happens through androidx.startup. On iOS it happens through an internal initializeMMKV call that uses the app's sandbox path. You never call MMKV.initialize() and never pass a Context. Add the dependency, call Documents.document(...), and you are done.

Note

On Android, this works because a <provider android:name="androidx.startup.InitializationProvider"> entry is merged into your app's manifest. You do not need to add anything yourself. Just do not remove or override that entry, for example with a conflicting tools:node="remove" that targets InitializationProvider. If you do, MMKV does not initialize and document access fails at runtime.

Supported platforms

Android and iOS (arm64 and simulatorArm64) are supported today. See Platform Support for the full table and for how MMKV is bound on each target.
