Guide

These guides walk through the public API one task at a time. Start here if you want the full picture and not just the quick tour.

  • Opening Documents: documents and collections, opening the same document more than once, and why there is no setup step.
  • Declaring Data Classes: when to use a nullable type or a constructor default, and a first-run crash to avoid.
  • Read & Write: set, update, and single-field update, and when to use each.
  • Reactivity: flow() and stateFlow(), with a snippet for Compose.
  • Field Delegates: binding a single field with by, without touching the whole document.
  • Field Decorators: transforming the bytes of a field, for example to encrypt or compress it.
  • Collections & Testing: separate MMKV files, the in-memory backend for tests, and the one-process rule.
  • Error Handling: what happens when a stored field cannot be decoded.
