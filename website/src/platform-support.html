How the library is configured

On Apple targets, MMKV is bound through the Kotlin CocoaPods plugin.

Both platforms share one public API, and all of it lives in commonMain. On both platforms the library initializes MMKV itself, so you have nothing to set up for it.

There is no JVM, desktop, or wasm target in this release.

See Shared KMP Persistence for what this means in practice.
