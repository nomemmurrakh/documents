Design Decisions

This is a curated index of the project's Architecture Decision Records (ADRs). It does not reproduce every one. It groups them by topic and gives each a one-line summary, with a link to the full record.

API shape

  • ADR-0004: Settled on "document" as the user-facing noun.
  • ADR-0007: Superseded by ADR-0016 An earlier shape for the root factory.
  • ADR-0008: The update builder returns a new value through copy() instead of changing a receiver.
  • ADR-0016: Documents is the entry point, and Collection is the handle for a named file.
  • ADR-0017: Dropped the MergeStrategy enum. The shape of the call now carries the intent.
  • ADR-0018: update(builder) is the verb, and update(prop, value) writes a single field.
  • ADR-0021: FieldDecorator is a bytes-in, bytes-out extension point for per-field encryption, compression, or logging.

Storage & serialization

  • ADR-0001: Each top-level field gets its own MMKV key.
  • ADR-0003: Fields are found through SerialDescriptor, never through reflection.
  • ADR-0006: Superseded by ADR-0015 The earlier per-type Codec design.
  • ADR-0015: One internal CBOR format replaces the pluggable Codec abstraction.

Reactivity & concurrency

  • ADR-0002: Reactivity is built on an in-memory SharedFlow change bus.
  • ADR-0011: The document API is synchronous with a non-suspending write lock. Only Flow collection is controlled by a dispatcher.
  • ADR-0022: A process-wide store runtime lets every instance of a document share one change bus and one write lock.

Platform & publishing

  • ADR-0005: Publish to Maven Central through macOS CI, not JitPack.
  • ADR-0012: The library initializes MMKV itself, so you do nothing.
  • ADR-0013: MMKV is bound on iOS through the Kotlin CocoaPods plugin.
  • ADR-0019: Dropped multiProcess mode. Storage is always single-process.
  • ADR-0020: The Kotlin package now matches the Maven groupId.

Errors & testing

  • ADR-0009: Decoding failures surface as DocumentDecodingException.
  • ADR-0010: field(prop, default) finds its serializer through a reified inline extension.
  • ADR-0014: Benchmarks run on a device, with a harness native to each platform.

For the full history behind any of these, see the complete ADR index on GitHub, or read Contributing to learn how to propose a new one.
